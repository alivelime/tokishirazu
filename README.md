# tokishirazu-media

`tokishirazu.llc` の企業サイトを、法人運営の信頼ページ＋案件別DRMプレセルLPの配信基盤として整備するメディアプロジェクト。初期構想は `media_site_plan.md`。

型: `code` / 作成: 2026-06-02

> 元の Start Bootstrap Agency テーマの README は `README.theme.md` に退避済み。ブラウザ確認用に Playwright MCP（インストール済み Chromium）を `.mcp.json` で設定済み。

## このプロジェクトのAIハーネス

このリポジトリは標準ハーネス（`harness` メタプロジェクトの蒸留版）で運用している。
新しいセッションは `CLAUDE.md` の「最初に読む順」に従うこと。

- 現在状態 → `STATUS.md`
- 進行中の未完作業 → `MISSIONS.md`
- 既知の落とし穴 → `learnings.md`
- 確定方針 → `decisions/`
- 作業ログ → `log.md`

ハーネスの自己点検: `bash scripts/validate-harness.sh`
