# ハーネス変更レビュー・ルブリック（8項目）

> 出典: movie_digest の `harness-architect`。
> ハーネス自体（settings/hooks/CLAUDE.md の構造ルール/役割定義/スキル）を変えるときは、
> 確定前にこの8項目を**具体的に引用して**判定する。「OK」だけは無効。可能なら独立サブエージェントで。

1. **失敗モードの封鎖** — F1(ソロ判断)/F2(手順未エンコード)/F3(目的喪失) のどれを、どう構造で閉じるか名指しできるか。
2. **決定性(F2)** — 手順が一意か。「適宜」で逃げていないか。別の人が同じ経路を辿れるか。
3. **相互確認の強制(F1)** — 高リスク判断が独立サブエージェントを**手順として**通るか（推奨止まりは不可）。
4. **目的の保持(F3)** — サブエージェントに固定された目的/評価基準を明示で渡すか。アンカリング防止。
5. **検出可能性(fail-safe)** — 手順を飛ばしたら検出できるか。黙ってスキップ/黙って既定値が起きないか。
6. **正本の所在** — その情報はどの階層が正本か一意に決まるか。コピー混入の隙はないか。
7. **非肥大・構造適合** — 既存の層・役割分担に収まるか。屋上屋・生ログ溜め込みになっていないか。
8. **可逆性** — 効かなかったとき撤去・差し戻せるか。

> 補足: deny は最後に立てる（L-001）。注入系hookと柵系hookを混ぜない。CLAUDE.md は薄く保つ。
