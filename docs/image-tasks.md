## 生成してほしい画像（優先度順）

### P1: OGP / SNS シェア画像
- **用途**: 各ページが SNS でシェアされたときのサムネイル（`og:image`）。
- **必要数**: 2〜3（トップ、メディア、記事用）。
- **推奨サイズ/比率**: 1200×630px（1.91:1）, PNG または JPG。
- **配置パス案**:
  - `img/og/home.png`（トップ）
  - `img/og/media.png`（メディア）
  - `img/og/article-video-ad-inhouse.png`（記事）
- **方向性**: ブランド色（青系 #2b59ff 系）＋ロゴ、テキストは大きめ。落ち着いたB2Bトーン。
- **反映方法**: 生成後、各 HTML の `og:image` を該当パスへ更新。

### P2: 記事ヘッダー / アイキャッチ
- **用途**: メディア記事のアイキャッチ（記事冒頭・一覧カード）。
- **必要数**: 1（記事「動画広告 内製化入門」用）。
- **推奨サイズ/比率**: 1600×900px（16:9）。
- **配置パス案**: `img/articles/video-ad-inhouse.jpg`
- **方向性**: 中小企業/動画/AIを連想させる抽象的なビジュアル（人物の顔出しは避ける）。
- **反映方法**: 記事 HTML の `.article__header` 直後にアイキャッチ `<img>` を追加、一覧カードにも反映。

### P3: トップ Hero ビジュアル
- **用途**: トップ Hero の右側に配置する装飾的なイラスト/グラフィック（現状はグラデーションのみ）。
- **必要数**: 1。
- **推奨サイズ/比率**: 1200×900px 程度、背景透過 PNG だと使いやすい。
- **配置パス案**: `img/hero/home-visual.png`
- **方向性**: 技術×メディアを示す抽象ビジュアル。

### P4: LP サンプル用ビジュアル（任意）
- **用途**: `lp/sample-ai-video/` の説得力を高める図解（任意）。
- **配置パス案**: `img/lp/sample-ai-video-hero.jpg`
- **注意**: サンプル雛形のため必須ではない。実案件LP作成時にまとめて用意でも可。

## 注意（共通）
- ブランド色のアクセントは `#2b59ff`（`assets/css/site.css` の `--accent`）。
- 人物・ロゴ・第三者の商標を含めない（権利配慮）。LP/記事で広告主ロゴを使う場合は提携後に公式素材を使用。
- ファイルサイズは Web 用に圧縮（OGPは ~300KB 以下目安）。
