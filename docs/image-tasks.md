## 1. ブランド視覚契約（Codex は色とトーンを発明しない。ここから引く）

**パレット（HEX 厳守）**

| 役割 | 名前 | HEX |
|---|---|---|
| 土台（紙） | 和紙白 | `#F5F1E8` |
| 文字（墨） | 墨 | `#15212B` |
| 基調の闇 | 墨紺 | `#001F3C` |
| 深み（水） | 淵ティール | `#0F3B38` |
| 差し色（熾火） | 熾火アンバー | `#C8822E` |
| 補助 | 鈍色 | `#5C6873` |

- **配分**: 和紙白＋墨の静かな面 70% / 墨紺・淵ティールの暗面 22% / 熾火アンバー **8%以下**（点でだけ。広い面に塗らない）。
- **タイポ**: 見出し＝明朝（Shippori Mincho / Noto Serif JP）、本文＝Noto Sans JP、数字・ラベル＝等幅（IBM Plex Mono）。文字を入れるなら明朝を基調に。
- **質感**: 静けさ・手仕事の墨・誇張のなさ・地に足。筆文字ロゴと血が繋がる「一筆の墨」。アナログの温度（純黒/純白を避ける）。
- **熾火の使い方**: 炎ではなく熾き火。暗面の中に細い線・小さな印・一点だけ、低く長く灯す。

- **目的**: SNS/検索でカード表示されたときの共有画像。現状は水中写真を流用中だが、小サイズでは社名が読めないため、**読める社名入りの静かなカード**を用意する。

- **Codex プロンプト（方向性）**:

### P2 —「いま歩いているフロンティア」3カードの墨スポット（任意・ブランド強化）✅ 完了（2026-06-03）

> Codex 生成 → `public/img/now/mark-video.png` / `mark-digest.png` / `mark-genearth.png` 配置済み。各カード先頭に `<img class="card__mark">` を挿入、CSS `.card__mark` を追加（実寸 76px。64px だと等高線が潰れたため調整）。3点とも手描き・内容固有・構図バラバラで、汎用アイコン化は回避できている。

- **目的**: トップ `#now` の3カードは現在テキストのみ。各カードの内容に合わせた**手描きの墨スポット**を一点ずつ添え、note 節（鮮やかな写真）と対比する「静かな墨」の面にする。
- **重要な線引き**: これは禁止された「揃いの汎用アイコンセット」ではない。**3つは構図も筆致もバラバラの、内容固有の一筆**であること。アイコン然とさせない。手で描いた墨の濃淡・かすれを残す。
- **配置パス / 各カードの中身**:
  - `img/now/mark-video.png` — カード01「動画生成AIの効く作り方を検証」: 墨の一筆で描いた**映像のフレーミング枠**（カメラの構図枠＋中心の一点）。
  - `img/now/mark-digest.png` — カード02「映像をショット分解して作り直すハーネス」: 墨で描いた**横長のフィルムを数コマに割った帯**（ショット分解の含意）。
  - `img/now/mark-genearth.png` — カード03「歩き回れる世界を生成で育てる」: 墨の等高線で描いた**小さな地形/球体と、そこを通る一本の小径**。
- **サイズ/形式**: 各 600×600px、**背景透過 PNG**。主線は墨 `#15212B`、和紙白の上に置く前提。熾火アンバーは**一点だけ**（例：中心点や小径の先）入れてよいが無くてもよい。
- **HTML/CSS 反映**: 各カード先頭に `<img class="card__mark" ...>` を追加（`.card__mark { width: 64px; height: 64px; margin-bottom: 1rem; }` 目安）。※実装は画像が揃ってから AI 側で対応。
- **判断**: もし墨スポットが「装飾の繰り返し」に見えるなら**入れない**。余白は埋めるものではなく効かせるもの。P1 を優先。

## 3. 共通ルール

- パレット・タイポは §1 厳守。**色やトーンを発明しない。**
- 人物・第三者の商標・ロゴを含めない（権利配慮）。自社ロゴは `img/logo02.svg` を使い、ラスタ生成で似せて描き起こさない。
- Web 用に圧縮（OGP ~300KB 以下、透過 PNG は軽量に）。
- 生成物のパスは上記どおり厳守（HTML 側を同名で待ち受けられるように）。新規ディレクトリ `img/og/`・`img/now/` は生成時に作成。
- 迷ったら判断基準はひとつ——**「静けさ・手仕事の墨・誇張のなさ・地に足」から外れていないか。** 外れるなら作らない。
