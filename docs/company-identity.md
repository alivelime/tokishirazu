## このサイトは何の場所か（最初に読む・最重要）

> 立場の芯は **「足跡を干す、後発開拓者」**。地図を配る教育者でもなく、時間を切り売りする受託業者でもない。新しい技術の波が来るたび最前線に着いて、実際に作り、その足跡を置いておく人。**このサイトの主役は、その"作ったもの"であって、作り手の内面の物語ではない。** 詩で語らず、具体物で語る。

- **何の場所か** — いま歩いている生成AI映像のフロンティアで、作ったもの・試したこと・分かったこと（つまずきも含めて）を置いておく場。
- **誰のためか** — 同じ方角（生成AI映像や、その周辺の新しい技術のフロンティア）へ向かう人・組織。「地図を配ってほしい人」でも「言った通りに作る業者を探している人」でもなく、**実装まで分かる先行者と“一緒に”探索したい人**。
- **なぜここを見るのか** — 二十年、新しい技術が実用に届くその最前線に毎回いた人間が、いままさに自分の手で「生成AIで映像を作るための道具」を組んでいる。作った道具・映像・つまずきが、生のまま、ここにある。借り物の解説ではない。
- **してほしい一歩** — まず作ったものを見てもらうこと。そして、同じフロンティアへ行くなら相談してもらうこと。
- **ここでやること／やらないこと** — やるのは **内製化支援**＝“自分たちで作れるようになりたい”に隣で付き合う（PoC・リサーチの伴走）。やらないのは“よく分からないから丸ごとやっておいて”——成果物の制作代行、丸投げの導入代行、時間を切り売りする受託開発。これは決別ではなく、差し出すのが“別の種類の仕事”だという線引き。

> **書き手の心得（後続エージェント向け・最重要の3つ）**
> 1. **足跡＝具体物で語る。** 「探索します」と看板を出すだけにしない。実際に作った動画、公開しているハーネス、試して分かったこと（成功も失敗も）を“その場で”見せる。約束ではなく現物。

## いま、どこを歩いているか

いま歩いているフロンティアは、**生成AIで映像を作るための「道具そのもの」を作ること**。映像を一本納品するのがゴールではない。狙っているのは **作りながら学習し続けるAIハーネス**——プロンプトを吐くだけの仕掛けではなく、作品の世界観・登場アセット・効くカメラワークまでを溜め込み、使うほど勘どころが効いてくる作業環境を、**いま組んでいる最中だ**。**ここがいちばん難しく、いちばん他と違うところ。** その「溜め込み」の見えている一端が、下のカメラワーク検証の公開——分かったことを一つずつ外に出して、次に効かせている。

正直に書く。Higgsfield の Cinema Studio や Figma の Weave のような、見栄えのするGUIはこちらにはない。Webアプリも作ったが、主戦場は Claude Code の上で淡々と動かす方で、見た目は地味だ。だが「派手なボタンの裏で実際に何が起きているか」を自分の手で組んで検証し、作り替えている——値打ちはそこにある。

動いているもの（約束ではなく現物）：

- **動画生成AIの「効く作り方」を一つずつ検証して公開している。** Kling 3.0／Seedance 2.0 などで、カメラワーク・アングル・演技（セリフと関係性だけでどこまで芝居が成立するか）を実験し、結果を記事にしている（→ note）。画像生成は Nano Banana Pro 等。
- **映像を分解して作り直すハーネス**（公開リポジトリ `movie_digest`）。気になった映像をショット単位に割り、その演出を調べ、生成AIで自分なりに組み直す道具。「あのシーンを、自分の手で再現できるようになる」ための実験場であり、上で言う“学習し続けるハーネス”の実物。
- **生成で「歩き回れる世界」を育てる長期プロジェクト**（公開リポジトリ `gen_earth`、SimEarth 的な方向）。

二十年、最前線で“作ってきた”目を、いまは「生成AIで作るための道具を作る」ことに向けている。捨てたものは何もない。

軸はひとつ——**作る力を、相手の“中”に残すかどうか**。成果物を丸ごと納品して終わる仕事はしない。やるのは **内製化支援**——自分たちで作れるようになるところまで、隣で一緒に立ち上げる。

**一緒にできること＝内製化支援（このサイトの目的）**

- 「作り方を知りたい」「この表現をどう作るか一緒に考えたい」「自社の映像制作パイプラインを立ち上げたい」——生成AIで“作る力そのもの”を、実装まで分かる人間が隣で一緒に育てる（PoC・リサーチの伴走）。
- たとえば——「この生成AIで、うちのこれは作れるのか。期間を区切って見極めたい」。そういう相談から一緒に始める。
- まずは作ったもの（作品・道具・検証）を見て、同じ方角だと感じたら相談してもらう。

**ここでやらないこと（決別ではなく、種類が違うだけ）**

- 「こういう映像を作って」「動画広告を量産して」——成果物を丸ごと請け負う制作代行。
- 「AI活用、よろしく」と丸投げされる導入代行・コンサルティング。
- 仕様を渡され、時間で実行するだけの受託開発。

要するに——**“よく分からないから丸ごとやっておいて”には応えない。“自分たちで作れるようになりたい”に、隣で付き合う。**

ひとことで言えば——**「作って」と仕様を渡される仕事は請けない。「これ、作れるか一緒に確かめよう」——そこから先を、一緒に歩く。**

## note との分業——「溜まる足跡」と「流れる足跡」

> これは運営の設計メモ。HP本文にこの分業の説明をそのまま載せる必要はない（読者目線では不要）。サイト構成とnote連携の方針として使う。

足跡は二か所に置く。役割をはっきり分ける。

- **このサイト（自社メディア）＝溜まる足跡。** まとまった・辞書のように引ける・時間で古びにくい情報を置く。「2023年から生成AIにどう取り組んできたか（年表）」「動画生成で効く作り方の決定版」のような、定番として価値が残るものを体系立てて束ねる柱記事の場所。**note の生ログをそのままコピーしない——複数のnote記事を編み直した"決定版/年表"にする**（重複コンテンツでどちらか沈むのを避ける）。最初の柱は「2023→いま、生成AIにどう取り組んできたか」の年表で決まり——古びず、"何をしてきたか"の証拠も兼ねる。
- **note（https://note.com/eto_shingo）＝流れる足跡。** その時々の検証ログ・時評・試行を、ブログのように時系列で出す場所。鮮度と量はここで稼ぐ。

連携の設計（3点）：
1. **双方向リンク。** 自社の柱記事 → 該当note群へ。各note記事の末尾・プロフィール → 該当する自社の柱記事へ。
2. **SEOは自社ドメインに貯める。** noteはドメインが強く、当面は検索で自社を食う。だから資産（定番の柱）は自社に置き、note からそこへ集める。育つのは数ヶ月の長期戦と腹を括る。
3. **相談（コンバージョン）は自社でしか起きない。** note には窓口が無いので、全note記事から自社サイトの「相談したい」へ必ず導線を張る。
4. **トップに note 最新記事のサムネイルを数本、手で並べる**（自動取得はしない）。“いまも更新されている生もの”だと一目で伝える動的な証拠。頻度は無理しない——間欠泉のように、出たときに足す。

> **後続エージェントへの注記**: トップに載せる note サムネ用に、現状の記事はおよそ3クラスタ——(1) **生成AI映像の検証**（Kling 3.0 カメラワーク一覧／演技検証、Nano Banana Pro 基本テク 等）、(2) **Claude Code × Obsidian で自分の作業環境・トリセツを作る話**、(3) **AI時評**（バブル論／エージェント論／「生成AIの時代にこそ西部劇を」等）。トップに出すなら、いま歩いているフロンティア＝(1) 生成AI映像系を優先して数本。サムネ・タイトル・公開日・URL は note から手動で転記する（記事URLは `https://note.com/eto_shingo/n/{key}` 形式）。

## ブランドデザイン（アートディレクション / 後続プロジェクト向け）

HP・LP・OGP・名刺などビジュアルを起こすときの基準。**色とトーンを各自で発明しない。ここから引く。**

### ロゴと写真が作る視覚の気分

手元の素材は、誇張のない・手仕事の・静かな佇まいを既に持っている。

- **ロゴ**（`img/logo02.svg`）— 墨の筆文字。濃紺と白、金箔調のかすれ。手で書いた一筆。
- **ヒーロー写真**（`img/header-bg.jpg`、代表自身の撮影）— 深い水の底から見上げた構図。暗い水、水面のさす光。

目指す視覚の気分は **「静けさ・手仕事の墨・誇張のなさ・地に足」**。

> **デザイナー向けの内部メモ。この気分の説明文や比喩を、そのままサイトのコピー／キャッチコピーにしないこと。** サイトの言葉は詩ではなく、作ったもの（足跡）で語る。視覚はロゴと写真自体に語らせ、抽象グラフィック（ネットワーク図・粒子・グラデーションの渦）で上書きしない。

### カラーパレット

旧サイトの「黒＋白＋黄」を捨てず、**ロゴと水中写真の実際の色で組み直したもの**。黒→墨紺、黄→熾火（炭の暖色）に置き換え、深い水のティールを足す。

| 役割 | 名前 | HEX | 使いどころ |
|---|---|---|---|
| 土台（紙） | 和紙白 | `#F5F1E8` | 背景の主役。本文の地。純白を避け、わずかに暖色のアナログな白 |
| 文字（墨） | 墨 | `#15212B` | 本文・見出しの文字（和紙白の上）。純黒でなく紺を含む炭 |
| 基調の闇 | 墨紺 | `#001F3C` | ロゴ由来。ヒーロー／フッター／区切りの暗面。沈める色 |
| 深み（水） | 淵ティール | `#0F3B38` | 写真の水の色。暗面の中の変化、大面積の補助 |
| 差し色（熾火） | 熾火アンバー | `#C8822E` | **唯一の暖色アクセント**。リンク・CTA・細い罫・一点の輝き |
| 補助文字 | 鈍色 | `#5C6873` | キャプション・補助テキスト・ラベル |

**配分の規律（これがブランドの肝）**

- 和紙白＋墨の静かな面 … 約 **70%**
- 墨紺／淵ティールの暗面（ヒーロー・フッター・節の区切り） … 約 **22%**
- 熾火アンバー … **8%以下**。ケチって使う。広い面に塗らない。

### 使い方の原則——三つの像を具体ルールに翻訳

- **炭火のように。** 熾火アンバーは「炎」ではなく「熾き火」。ネオンに光らせない、広く塗らない。暗い面の中に、細い線・小さな印・一点だけ、低く長く灯る。暖かいが静か。
- **間欠泉のように。** ページの大半は静か（和紙＋墨）に保ち、色と動きは**まれに、決定的に**だけ訪れる。CTA・節の切り替わり・ホバー——溜めてから一度きりの噴き上げ。自動カルーセルや常時ループのアニメは置かない。動きは一つ、ゆっくり、意図して。
- **一歩ずつ地に足をつけて。** しっかりした余白とグリッド、本物の写真（ヒーロー）と本物の作品（足跡＝制作した映像）、印刷物のように読める字組み。安っぽいグラデや発光で「進んでる感」を演出しない。非対称と余白で落ち着かせる。中央寄せで全部を揃えない。

**ヒーローの扱い**: `header-bg.jpg` を主役に。写真の上に墨紺→透明の暗がりだけを重ね（テック調の紫青グラデは禁止）、和紙白の文字を置き、CTA一つにだけ熾火を差す。写真がブランドを背負っているので、上に飾りを足さない。**ヒーローの見出しは詩ではなく、いま歩いている場所を一行で言う**（例：「いま、生成AI映像のフロンティアを歩いている。その足跡を干す場所です。」の方向。実コピーは要推敲）。

### タイポグラフィ

筆文字ロゴと「職人が淡々と語る」温度に合わせ、**見出しは明朝（墨・印刷・地に足の質感）、本文は読みやすい角ゴシック**で対比させる。

- 見出し（日本語）: Shippori Mincho / Noto Serif JP など明朝系。一筆ロゴと血が繋がる。
- 本文（日本語）: Noto Sans JP（旧サイト踏襲。可読性の土台）。
- 数字・技術ラベル・コード: 等幅（例 IBM Plex Mono / Roboto Mono）。エンジニアの誠実さを字でも示す。
- 大きく強い字は墨か墨紺で。熾火は語の下線・小さな見出し記号など**点**で使い、見出し全体を塗らない。

### やってはいけないこと（AI感・量産サイト回避の具体）

- 紫〜青のテック・グラデーション、ガラス質（glassmorphism）、発光ネオン、粒子・抽象ネットワーク背景。
- 絵文字アイコン、ストックの「未来都市／回路」イメージ、同一の3カラム機能カードに汎用アイコン。
- 全要素の中央寄せ、隙のない詰め込み、画面いっぱいの自動アニメ。
- 純黒 `#000` と純白 `#FFF` のベタ。必ず墨（`#15212B`）と和紙白（`#F5F1E8`）に寄せ、アナログの温度を残す。
- 中身のない装飾の繰り返し。**余白は埋めるものではなく、効かせるもの。**

## トーン&マナー（後続プロジェクト向けメモ）

HP・LP・プロフィールがこの会社の声を再現するための指針。**ここを外すと「ときしらず」ではなくなる。**

**佇まいの基準**

- 腕のいい職人が、自分の仕事を淡々と語るくらいの温度で。企業然とした硬さも、個人サイトのはっちゃけも要らない。
- 自己宣伝より、**作ったもの（足跡）の積み重ね**で信頼を立てる。経歴は裸で置かず、必ず「だからいまこれが作れる／一緒に行ける」に折り返す。
- 変化のさなかにあることは、焦りや断絶ではなく、自然な移ろいとして滲ませる。

**絶対に踏んではいけない地雷**

1. **約束で終わらせない（足跡＝現物を見せよ）。** 「探索します」「一緒に歩けます」と言うだけにしない。実際に作った映像、公開しているハーネス、試して分かったことを、その場で見せる。看板でなく現物。
2. **内面の旅・自己分析にしない（独り言の禁止）。** ページの主役は“作ったもの”と“向かっている場所”。創業者の心境・葛藤・自己分析を物語の中心に据えない。**詩的なキャッチコピーを本文・見出しに置かない**——禁止語の例：「光のさす上へ昇る」「現場の温度（で書ける）」「机上の評論ではない」「静かな窓口」。測れない／自分だけが気持ちいい言葉は、具体物に置き換える。
3. **内輪用語を持ち込まない。** Vault の私的概念（応答型OS、むしゃむしゃ、再構築、測量士、干物プラットフォーム、三本杭、作品の固有名や取引先・人物の内輪呼称など）をそのまま出さない。第三者が辞書なしで分かる言葉だけ。
4. **経歴は読者の関心へ折り返す。** WebRTC・メタバース等の専門実績を、権威マウントで並べない。仮想敵（評論家・量産メディア）を立てて自分を持ち上げない。否定形は最小限、肯定形で。
5. **「やらないこと」は決別でなく線引きとして書く。** 「受託はやめた」「Web開発から離れる」とは書かない。重心の移動は連続として描き、やらない仕事は“ここで差し出すのが別の種類だから”と淡々と。
6. **気負いの常套句を避ける。** 「全力で」「情熱を持って」「お客様第一で」の類を使わない。静かに、事実と足跡で語る。
7. **「で、結局ここは何の場所で、私と何ができるの？」を残さない。** 読み終えた赤の他人が、「この人はいま何のフロンティアを歩いていて、同じ方角なら一緒に何ができるのか」を一息で言えること。

**判断に迷ったら**

> これを読んだ赤の他人が、「この人が実際に作ったものは何か」「同じ方角へ行くなら声をかける価値があるか」を掴めるか。

それだけを基準にする。内側の豊かさは内側（Vault）に置いておく。外に出すのは、足跡——外から見て本物だと分かる現物——だけ。
